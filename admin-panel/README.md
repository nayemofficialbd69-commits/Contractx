# ConnectX Messenger - Admin Panel

A secure, responsive web administration console for ConnectX Messenger.

## Features
- **User Moderation**: Search by Public ID (`CX-XXXXXXXX`) or `@username`, inspect accounts, suspend with mandatory reason, and restore accounts.
- **Remote Config & Feature Flags**: Dynamically toggle WebRTC Audio/Video calls, Screen Sharing, Voice Messages, File Uploads, and Maintenance Mode.
- **Audit Logs**: Immutable log of all administrative actions with timestamp and admin credentials.
- **Global Announcements**: Broadcast high-visibility notices to connected Android clients.

## Quick Start
```bash
npm install
npm run dev
```

Default access key: `ConnectX-Admin-2026` or `admin123`.
